## Launch Curseforge [step]
If you don't have the app, you can download it [here](https://www.curseforge.com/download/app)

Once there, choose the <u>**DOWNLOAD STANDALONE**</u> option

## Start the import [step]
Click on the <u>**import**</u> button
![first](https://cdn.r4men.com/girls-server/images/curseforge-choose-import.png)

## Import via a zip file [step]
Click on the <u>**Choose .zip file**</u> button
![second](https://cdn.r4men.com/girls-server/images/curseforge-choose-zip.png)

## Select file [step]
Select the zip file (it's probably in your download folder)
![third](https://cdn.r4men.com/girls-server/images/file-explorer-zip.png)

## Last step! [step]
Make sure you check the checkbox that shows up and then select the <u>**All Files**</u> button

![fourth](https://cdn.r4men.com/girls-server/images/curseforge-checkbox.png)
